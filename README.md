# Pallanuoto 3D

Gioco di pallanuoto 3D nel browser: Italia contro Ungheria, regole World Aquatics 2026, schemi, lotta al centro, tastiera, controller e comandi touch.

**Gioca:** apri `index.html` nel browser, oppure la versione pubblicata su GitHub Pages (Settings → Pages → Deploy from branch → `main`).

- `index.html` — tutto il gioco (Three.js da CDN)
- `CLAUDE.md` — memoria del progetto per Claude Code: decisioni, regole, problemi aperti, roadmap
- `tests/simula_partite.py` — partite simulate senza grafica per trovare errori
