# Pallanuotista per Plask — mani e polsi corretti

Modello GLB separato per lavorare alle animazioni in Plask: 52 ossa pesate, dita articolate, 34.550 triangoli. Nessuna animazione registrata inclusa. Questo è lo stesso file già consegnato ad Ale, non una nuova versione del modello.

Scaricare `pallanuotista-plask.zip` ed estrarre `pallanuotista-plask.glb`, oppure scaricare direttamente il GLB. Il modello runtime della PR #64 rimane separato. Nessuna modifica a main, al gioco o al suo volto viene applicata da questo ramo.
